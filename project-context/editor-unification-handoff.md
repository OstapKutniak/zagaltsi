## Головна ціль (запит користувача, дослівно за змістом)

Редактори **Меню** і **Локацій** мають отримати **весь функціонал «Редактора Мандр»**
(це вкладка `data-tab="level"` = `src/level/editor.ts`, 3784 рядки — еталон), лише з
**іншими бібліотеками** + свої додаткові налаштування. Конкретно:

1. **Перенести ПКМ-логіку плановості + анімації + деформації** розміщених ассетів у
   редактор **меню** і редактор **локацій** (зараз повноцінно є лише в level-редакторі).
2. **Редактор меню:** ліва бібліотека має працювати **тим самим механізмом карток і
   керуванням**, що й в інших редакторах (зараз у меню — своя спрощена бібліотека).
3. **Редактор локацій:**
   - **прибрати підменю ефектів, що я робив під Дуб конкретно** — це список **шарів
     туману** (`fogs` / `FogLayer`, UI `#loc-fogList` + `#loc-addFog`, функція
     `renderFogs()` у `src/location/editor.ts`);
   - замість нього **перенести всю панель з level-редактора**: **плановість (per-layer
     tint), погода (дощ/сніг/туман/блискавка), баланс кольору, віньєтка** — це секція
     «Атмосфера» в `src/level/editor.ts` (рядки ~1778–2100, функція будує праву панель
     над об'єктом `atm` типу `Atmosphere` з `src/level/atmosphere.ts`);
   - **додати окрему бібліотечну менюшку «Фон»** (поряд із менюшкою «Будівлі»): туди
     кидати ассети, які **НЕ виділяються/не підсвічуються** (фоновий шар, статичний декор).
4. **20:9 за замовчуванням УВІМК** у редакторі меню та локацій, і щоб рамка **фіксувала
   саме той шматок**, що фактично показується в грі.
5. Підсумок: menu/location = level-редактор, інші бібліотеки + свої налаштування.

## Що ВЖЕ зроблено (усе на `main`, задеплоєно)

Редактор **меню** (`src/menu/editor.ts` + `src/scenes/MenuScene.ts` + `mn-*` у `studio.html`):
- Дефолт = **6 справжніх кнопок гри** (з «Житло»→home), координати як у `MenuScene.ITEMS`.
- Кнопка **«Прев'ю 20:9»** — чисте WYSIWYG (кадр 20:9 без чрому редактора). Тепер
  **увімкнена за замовчуванням** (заходиш — одразу фактичний кадр; тиснеш кнопку — редагування).
- **Розміщення PNG-об'єктів на сторінці + плановість** (перша частина п.1 для меню):
  - `MenuObject` у схемі `MenuPage.objects` (url вбудований, як bg). Типи `anim?/deform?`
    зарезервовані спільними з level (`PlacedAnim`/`PlacedDeform` з `LevelView`).
  - ЛКМ по ассету або ПКМ→«Розмістити» → кладе об'єкт. Перетяг — рух, кут-гізмо — масштаб.
  - **ПКМ по об'єкту**: на передній/задній план, вперед/назад, дзеркало, обертання,
    масштаб, видалити. `[` `]` — плановість, `Del` — видалити.
  - Плановість = depth **1..7** (5 — рівень персонажа/вогню; кнопки завжди зверху, depth 8).
  - `MenuScene.buildObjects()` малює їх у грі з відповідною глибиною.
  - **Анімації/деформації для меню ЩЕ НЕМА** — це наступний етап (task #16).

## Рекомендований план (ордер) для продовження

**Стратегія:** винести з `level/editor.ts` спільні модулі й перевикористати, бо копіювати
3000+ рядків у кожен редактор — погано. Але level-редактор монолітний (усе в замиканні
над `state`/`draw`/`canvas`), тож екстракція інвазивна — робити акуратно, по модулю, з
верифікацією (headless Playwright: `/opt/node22/lib/node_modules/playwright`, launch
`executablePath:'/opt/pw-browsers/chromium'`; Firebase у headless не працює — ігнорувати
ERR_TUNNEL).

1. **Спільний модуль панелі атмосфери** (task #17) — найсамодостатніший. Функція
   `buildAtmospherePanel(container, getAtm, save, redraw)` над типом `Atmosphere`.
   - Використати в **локації**: додати `LocationDoc.atmosphere?: Atmosphere`, прибрати
     `fogs`/`renderFogs`/`#loc-fogList`, вставити панель. **Гра (`LocationScene`) має
     рендерити атмосферу** (баланс кольору/віньєтка/погода) — портувати з рендер-частини
     level (draw-секція 566–760) або зі спільного апплаєра, якщо винесемо.
   - (Опційно) також у меню.
2. **Спільний модуль розміщених об'єктів** (task #18): `Placed`-подібна система +
   ПКМ-меню (плановість/анімація/деформація) + рендер (з `LevelView` хелперами).
   - У **меню**: розширити наявний `MenuObject` до anim/deform (task #16), під'єднати
     ПКМ-меню анімації/деформації, `MenuScene` — програвати (використати `animOffset`/
     `deformImgPt`/`deformKfAt`, як `LevelView`).

3. **Бібліотека карток як в інших редакторах** — у меню зробити ліву панель тим самим

  автора `noreply@anthropic.com`; «N» = лише відсутній GPG-підпис (не полагодити без ключа).
  Коміти вже в задеплоєному `main` — `--amend`/rebase+force-push НЕ робити (деструктивно).
- Деплой = push у `main`. Розробка — на `claude/back-pain-anxiety-system-yk92py`,
  зливати в main поетапно стабільними шматками.
