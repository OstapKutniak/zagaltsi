# Bretwalda — словник українського перекладу карт

Єдине джерело термінів для вкладишів (`bretwalda.html`, набір
`public/bretwalda/cards.json`). Звірено з неофіційним українським перекладом
правил із BGG (2022) 15.07.2026; де розійшлися — рішення Остапа зафіксовані тут.
**Нові переклади карток робити тільки за цим словником.**

## Колоди (розділи в редакторі)

| Оригінал | Переклад | Примітка |
|---|---|---|
| Lordship cards | карти Влади | як у правилах BGG (було «карти Володінь» — замінено скрізь) |
| Chronicle cards | карти Хроніки, колода Хронік | збігається з правилами |

## Значки-токени редактора

| Токен | Що означає в грі |
|---|---|
| {монета} | золото |
| {товар} | їжа (розетка; у правилах «жетони їжі» — токен історично зветься «товар») |
| {кубик} | бойовий куб |
| {меч} | меч (рана/бій) |
| {рух} | очко руху |

Числа пишемо перед значком: «Скинь 3 {монета}».

## Стиль

- Звертання на «ти», наказовий спосіб: «Скинь», «Контролюй», «Виграй», «Постав».
- Назви ігрових об'єктів (Місто, Порт, Абатство, Правитель, Претендент,
  Столиця) — з великої; загальні слова (корабель, будівля, область) — з малої.
- Рядки на картці розбиваємо вручну `\n`, по ~30 символів.
